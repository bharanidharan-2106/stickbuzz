# StickBuzz 

StickBuzz is a real-time hockey live score Android application built using Java in Android Studio with Firebase Realtime Database.

The app provides live hockey match updates including scores, goal scorers, penalty cards, upcoming matches, team squads, tournaments, and match schedules.

---

# Features

## User Features

- View live hockey matches
- View finished match results
- View upcoming matches
- View live score updates instantly
- View goal scorers with goal time
- View penalty cards with time
- View match scorecards
- View team squads for both teams
- Real-time updates without refreshing

---

## Admin Features

- Create and manage tournaments
- Create and schedule matches
- Update live match scores
- Add goal scorers with scoring time
- Add penalty cards with time
- Update match scorecards live
- Manage team squad players
- Publish upcoming match schedules
